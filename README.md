# creative-coding-study-sounds

# Project Name
Study Sounds is a creative coding project created with TunePad's Python programming. The goal of this project is to produce a soothing background music track that students can listen to while focusing on academic duties, studying, or finishing assignments.

My own experience of having trouble finding appropriate background music while studying served as the basis for Study Sounds. I wanted to make my own calming sound that may promote concentration without being disturbing because I've always found that listening to music helps me focus.

Project Objectives:
Study Sounds' primary goals were to:

## Features
Calm Piano Chords: Soft piano chords provide a peaceful musical setting that is ideal for studying.
Layered Musical Composition: A full musical track is produced by combining various piano melodies, bass notes, and drum beats.
Rhythmic Patterns: Note lengths, tempo, and musical sequences can all be controlled with Python programming.
Multiple Coding Cells: Individual development and modification of various instrumental levels is made possible by distinct coding cells.



## Usage

Open the Study Sounds project on TunePad
Navigate through the different musical tracks and Python coding cells.
Click on a coding cell to view the Python commands used to create the music.
Run the individual coding cells to hear the different musical layers.
Play the tracks together to listen to the complete Study Sounds composition.
Users can experiment with the code by adjusting notes, rhythms and durations to create different sounds.
How does one go about using it?

# First soft piano chord
playNote(48, beats=8)
playNote(52, beats=8)
playNote(55, beats=8)

# Second soft piano chord
playNote(45, beats=8)
playNote(48, beats=8)
playNote(52, beats=8)

This code demonstrates how the playNote() function is used to create soft piano chords. The numbers represent the pitch of each note, while beats=8 determines how long each note plays.
